# Personal Portfolio

## About the Project
This project is a personal portfolio website created from scratch
using HTML, CSS, and JavaScript.

The purpose of this website is to introduce myself, showcase my
skills, and display my projects in one place.

## Features
- Responsive navigation bar.
- About Me section with a personal introduction.
- Skills grid to display technical skills.
- Project Showcase featuring my work.
- Hobbies section.
- Contact form.
- Footer with additional information.
- Interactive theme switcher to change the website's appearance.

## Technologies Used
- HTML5: To structure the website.
- CSS3: To style the website and create responsive layouts.
- JavaScript ES6+: To add interactivity and handle user events.
- Git: To track changes and manage the project.

## Responsive Design
The website uses Flexbox and CSS media queries to adapt
to different screen sizes, including mobile phones, tablets,
and desktop computers.

## JavaScript Interaction
The theme switcher allows users to change the website's
background color or theme by clicking a button.

This interaction follows the event lifecycle:
User Action -> Event Firing -> JavaScript Callback -> DOM/CSS Update.

1. Download or clone the project.
